ERROR: "Could not load file or assembly 'SixLabors.ImageSharp, Version=3.0.0.0'"
================================================================================

CAUSE: DLL files are blocked by Windows security after USB transfer

QUICK FIX (30 seconds):
1. Close the application (Ctrl+C in Command window)
2. Double-click: UNBLOCK_FILES.bat
3. Wait for "SUCCESS" message
4. Double-click: START_HERE.bat
5. Application should start normally

ALTERNATIVE FIX (if UNBLOCK_FILES.bat fails):
1. Right-click on the ProjectPublish folder
2. Properties → General tab
3. Check "Unblock" at the bottom
4. Click "Apply"
5. Select "Apply to all subfolders and files"
6. Click OK
7. Run START_HERE.bat again

WHY THIS HAPPENS:
Windows marks files transferred via USB as potentially unsafe. This doesn't
mean the DLL is missing - it's present but blocked from loading.

ERROR: "Port 5000 is already in use" OR "Address already in use"
================================================================================

CAUSE: Another application is using port 5000

QUICK FIX Method 1 (30 seconds):
1. Open Command Prompt
2. Run: netstat -ano | findstr ":5000"
3. Note the PID number (last column)
4. Open Task Manager (Ctrl+Shift+Esc)
5. Details tab → Find process with that PID
6. Right-click → End Task
7. Run START_HERE.bat again

QUICK FIX Method 2 (if Method 1 fails):
1. Find other ShiftManager instances:
   tasklist | findstr ShiftManager
2. Kill all instances:
   taskkill /F /IM ShiftManager.exe
3. Wait 5 seconds
4. Run START_HERE.bat again

PERMANENT FIX (change port):
1. Open appsettings.json in Notepad
2. Find line: "Urls": "http://localhost:5000"
3. Change to: "Urls": "http://localhost:5001"
4. Save file
5. Run START_HERE.bat
6. Open browser to: http://localhost:5001

ERROR: "Invalid username or password" during login
================================================================================

CAUSE: Admin password not configured or incorrect

QUICK FIX (1 minute):
1. Open appsettings.json in Notepad
2. Find line: "SEED_ADMIN_PASSWORD": ""
3. If empty, add password: "SEED_ADMIN_PASSWORD": "ShareholderDemo2025!"
4. Save and close
5. The password is case-sensitive!
6. Login with:
   Email: admin@local
   Password: ShareholderDemo2025!

NOTE: Username is ALWAYS admin@local (lowercase, with @local suffix)


================================================================================
ERROR: "ShiftManager.exe is not recognized" OR "Cannot find file"
================================================================================

CAUSE: Running from wrong directory

QUICK FIX (10 seconds):
1. Open File Explorer
2. Navigate to the folder containing ShiftManager.exe
3. Verify you see: ShiftManager.exe, START_HERE.bat, etc.
4. In this folder, double-click START_HERE.bat
5. Do NOT run from desktop shortcut or different folder


================================================================================
ERROR: Application starts but crashes immediately (no error message)
================================================================================

CAUSE: Usually corrupted database or missing dependencies

QUICK FIX Method 1 - Delete Database (30 seconds):
1. Close application (Ctrl+C)
2. Look for these files in the folder:
   - app.db
   - app.db-shm
   - app.db-wal
   - wwwroot/Data/shiftmanager.db
3. Delete ALL of them
4. Run START_HERE.bat
5. Application will recreate database from scratch

QUICK FIX Method 2 - Run Emergency Fix:
1. Close application
2. Double-click: QUICK_FIX.bat
3. Follow the prompts
4. Application should start normally


================================================================================
ERROR: Application starts but shows blank white page in browser
================================================================================

CAUSE: Usually JavaScript errors or browser cache

QUICK FIX (20 seconds):
1. Press Ctrl+Shift+R (hard refresh, clears cache)
2. If still blank, press F12 (open Developer Tools)
3. Check Console tab for red errors
4. Most common: Try a different browser (Chrome → Edge or vice versa)
5. Clear browser cache completely
6. Restart browser


================================================================================
ERROR: "Access denied" OR "Permission denied"
================================================================================

CAUSE: Folder permissions or antivirus blocking

QUICK FIX Method 1 - Run as Administrator:
1. Right-click START_HERE.bat
2. Select "Run as administrator"
3. Click "Yes" when prompted
4. Application should start with elevated permissions

QUICK FIX Method 2 - Check Antivirus:
1. Open Windows Security
2. Virus & threat protection → Protection history
3. Look for quarantined files
4. If ShiftManager.exe or DLLs are quarantined, restore them
5. Add folder to exclusions:
   Windows Security → Virus & threat protection
   → Manage settings → Exclusions
   → Add exclusion → Folder
   → Select C:\ShiftManager\ProjectPublish\


================================================================================
ERROR: Application works but crashes when uploading avatars
================================================================================

CAUSE: SixLabors.ImageSharp.dll is blocked or corrupted

QUICK FIX (1 minute):
1. Close application
2. Run VERIFY_FILES.bat
3. Check if SixLabors.ImageSharp.dll is listed as blocked
4. Run UNBLOCK_FILES.bat
5. Start application again
6. Try uploading avatar again

VERIFY INTEGRITY:
1. Open Command Prompt
2. Run: CertUtil -hashfile SixLabors.ImageSharp.dll SHA256
3. Compare with hash in DLL_CHECKSUMS.txt
4. If different, recopy file from USB


================================================================================
ERROR: "Database is locked" OR "Cannot write to database"
================================================================================

CAUSE: Multiple instances running or file locks

QUICK FIX (30 seconds):
1. Close all browser windows
2. Open Task Manager (Ctrl+Shift+Esc)
3. Find ALL ShiftManager.exe processes
4. End ALL of them
5. Wait 5 seconds for file locks to release
6. Run START_HERE.bat
7. Database should be accessible now


================================================================================
ERROR: "Could not load file or assembly 'Microsoft.EntityFrameworkCore.Sqlite'"
================================================================================

CAUSE: SQLite DLLs are blocked (same as ImageSharp issue)

QUICK FIX (30 seconds):
1. Close application (Ctrl+C)
2. Run UNBLOCK_FILES.bat (updated version checks all SQLite DLLs)
3. Run START_HERE.bat
4. Should work now

VERIFY:
1. Check these DLLs exist and are unblocked:
   - Microsoft.EntityFrameworkCore.Sqlite.dll
   - SQLitePCLRaw.provider.e_sqlite3.dll
   - Microsoft.Data.Sqlite.dll
   - e_sqlite3.dll


================================================================================
ERROR: Hebrew text shows as squares/boxes or right-to-left doesn't work
================================================================================

CAUSE: Missing fonts or browser language settings

QUICK FIX (browser-dependent):
1. Install Hebrew language pack in Windows
2. Chrome: Settings → Languages → Add Hebrew
3. Edge: Settings → Languages → Add Hebrew
4. Restart browser
5. Refresh page (Ctrl+Shift+R)

================================================================================
DIAGNOSTIC COMMANDS (For Investigating Issues)
================================================================================

Check if application is running:
  > tasklist | findstr ShiftManager

Check port 5000 status:
  > netstat -ano | findstr ":5000"

Verify DLL is unblocked (PowerShell):
  > powershell "Test-Path 'SixLabors.ImageSharp.dll:Zone.Identifier'"
  (Should return: False = unblocked, True = blocked)

Check DLL hash:
  > CertUtil -hashfile SixLabors.ImageSharp.dll SHA256
  (Compare with DLL_CHECKSUMS.txt)

Count DLL files:
  > dir /s /b *.dll | find /c ".dll"
  (Should be 330-340)

Check free disk space:
  > dir C:\
  (Look for "bytes free" - should be >1GB)
