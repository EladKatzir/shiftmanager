SHIFT TYPES
================================================================================

The following shift types are automatically seeded:

1. MORNING (08:00 - 16:00)
2. NOON    (16:00 - 00:00)
3. NIGHT   (00:00 - 08:00)
4. MIDDLE  (12:00 - 20:00)
5. OFFLINE (00:00 - 00:00) - Special non-working shift

All shift types can be customized after deployment.

================================================================================
ON-DUTY TYPES
================================================================================

Built-in on-duty assignment types:

1. Hakam (Duty Officer)
2. Lead  (Team Lead)

These are enum values, always available, no seeding required.

================================================================================
USER ROLES
================================================================================

Six built-in roles with different permission levels:

1. Owner     - Full system access, all companies
2. Director  - Full company access, manage all users
3. Manager   - Manage shifts and employees
4. Assigner  - Create and assign shifts
5. Employee  - View own shifts, request changes
6. Trainee   - Limited access, view only

SECURITY FEATURES
================================================================================

* Cookie-based authentication (secure, httpOnly)
* Password hashing (bcrypt-style)
* Role-based authorization
* Company-scoped data isolation
* SQL injection prevention (EF Core parameterized queries)
* XSS protection (Razor automatic encoding)
* CSRF protection (anti-forgery tokens)

Post-Deployment Security Steps:
  1. Set strong admin password
  2. Protect appsettings.json with NTFS permissions
  3. Configure HTTPS for network access
  4. Enable Windows Firewall rules
  5. Regular database backups
  6. Run as Windows Service (not as user)
