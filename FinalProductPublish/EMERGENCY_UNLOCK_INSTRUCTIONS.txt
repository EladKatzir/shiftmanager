═══════════════════════════════════════════════════════════════════════
UNDERSTANDING THE ISSUE
═══════════════════════════════════════════════════════════════════════

PASSWORD SEEDING ONLY HAPPENS ONCE:

When app.db is FIRST created:
  1. Application reads SEED_ADMIN_PASSWORD from appsettings.json
  2. Creates admin@local user with that password
  3. Stores hashed password in database

After database exists:
  1. Application IGNORES SEED_ADMIN_PASSWORD
  2. Uses password stored in database
  3. Changing appsettings.json has NO EFFECT

To change admin password AFTER database exists:
  - Login to the application
  - Go to user management
  - Change password through UI
  OR
  - Delete database and let it recreate
