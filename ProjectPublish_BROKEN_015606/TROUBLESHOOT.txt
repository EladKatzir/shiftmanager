================================================================================
          TROUBLESHOOTING: SixLabors.ImageSharp Missing Error
================================================================================

ERROR MESSAGE:
"Could not load file or assembly 'SixLabors.ImageSharp, Version=3.0.0.0'"

CAUSE:
The SixLabors.ImageSharp.dll file is either:
1. Missing from the ProjectPublish folder on the air-gapped machine
2. Corrupted during USB transfer
3. Blocked by antivirus/Windows security

================================================================================
SOLUTION 1: VERIFY FILES ON AIR-GAPPED MACHINE
================================================================================

On the air-gapped machine, run these commands in PowerShell from the
ProjectPublish folder:

1. Check if file exists:
   dir SixLabors.ImageSharp.dll

2. Expected output:
   File should be ~2.1 MB (2,195,456 bytes)

3. Count total DLLs:
   (Get-ChildItem -Recurse -Filter *.dll | Measure-Object).Count

4. Expected: 336 DLL files

================================================================================
SOLUTION 2: IF FILE IS MISSING - RECOPY FROM USB
================================================================================

1. DELETE the ProjectPublish folder on the air-gapped machine
2. RECOPY the ENTIRE ProjectPublish folder from USB drive
3. Verify file count matches

IMPORTANT: Copy the ENTIRE folder, not individual files!

================================================================================
SOLUTION 3: CHECK WINDOWS DEFENDER/ANTIVIRUS
================================================================================

Windows might have blocked/quarantined DLL files:

1. Right-click SixLabors.ImageSharp.dll
2. Properties → General tab
3. If you see "This file came from another computer and might be blocked"
4. Click "Unblock" button
5. Click Apply
6. Repeat for ALL DLL files or use PowerShell:

PowerShell command to unblock all files:
Get-ChildItem -Recurse | Unblock-File

================================================================================
SOLUTION 4: VERIFY USB TRANSFER
================================================================================

1. Check USB drive for file:
   - Locate ProjectPublish/SixLabors.ImageSharp.dll on USB
   - Size should be 2,195,456 bytes (2.1 MB)

2. If file is on USB but not on air-gapped machine:
   - Copy failed partially
   - Recopy the entire folder

================================================================================
SOLUTION 5: REBUILD PACKAGE (Last Resort)
================================================================================

If recopy doesn't work, on the DEVELOPMENT machine:

1. Delete ProjectPublish folder
2. Run: dotnet clean
3. Run: dotnet publish -c Release -r win-x64 --self-contained -o ProjectPublish
4. Copy fresh build to USB
5. Transfer to air-gapped machine
