Getting Started
Click any empty cell to start typing. Your input searches for employees to assign. Press Enter to confirm, Esc to cancel.
Commands
📅 /shift Assign shift
🧹 /chore Assign chore → select type → enter title
🛡️ /duty Assign day shift
🏠 /home HOME shift
Text Notes
Type any text without / to save it as a calendar note on that cell. Notes appear as 📝 badges on other calendar views.
Available in user-mode only (Shifts page).

Design Decisions

  • Slash commands stay in English in both tabs — /shift not /משמרת — because that's what the user actually types
  • Keyboard keys stay LTR (dir="ltr" on <kbd>) even in Hebrew tab
  • Auto-selects tab based on document.documentElement.lang — Hebrew users see עברית first
  • Page availability is static — always shows all 3 pages, so users learn what's available elsewhere
  • ? button appears next to the ⚡ Quick Entry toggle, same @if (Model.CanEdit) gate
  • Accessible — uses existing ModalFocus.open/close() for focus trap, ESC to close
