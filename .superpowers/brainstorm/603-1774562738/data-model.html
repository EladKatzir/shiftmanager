Widget Data Flow:
① User loads page → OnCallWidgetViewComponent invoked
② WidgetService reads QuickInfoConfig for user's molecule
③ For each OnCallRole config → query OnDuty table for today's date + that duty type
④ For each Store config → query Store + StoreHoursEntry for today's day-of-week
⑤ Compute status: OPEN (in window), BREAK (between windows), CLOSED (past all windows)
⑥ Return assembled widget data to view
