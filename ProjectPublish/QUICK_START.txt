FASTEST WAY TO GET RUNNING (3 SIMPLE STEPS):
=============================================

STEP 1: Set Admin Password
---------------------------
Open appsettings.json in Notepad and edit these lines:

FROM:
  "SEED_ADMIN_PASSWORD": "",
  "SEED_DIRECTOR_PASSWORD": ""

TO:
  "SEED_ADMIN_PASSWORD": "MySecurePass123!",
  "SEED_DIRECTOR_PASSWORD": ""

Save and close.

STEP 2: Run the Application
----------------------------
Double-click ShiftManager.exe

You should see:
  "Now listening on: http://localhost:5000"

STEP 3: Login
-------------
Open your web browser and go to:
  http://localhost:5000

Login with:
  Email: admin@local
  Password: MySecurePass123!  (whatever you set in appsettings.json)

THAT'S IT! You're done!

================================================================================
COMMON QUESTIONS:
================================================================================

Q: The app crashes with "SEED_ADMIN_PASSWORD must be set"
A: You forgot to edit appsettings.json (see STEP 1 above)

Q: Can I access this from another computer?
A: Yes, but you need to configure the firewall and binding.
   See DEPLOYMENT_GUIDE.txt Step 6 for details.

Q: Where is the database stored?
A: In the same folder as ShiftManager.exe, it's called app.db
   It will be created automatically on first run.

Q: Can I change the port from 5000?
A: Yes, see DEPLOYMENT_GUIDE.txt Step 6

Q: How do I run this as a Windows Service?
A: See DEPLOYMENT_GUIDE.txt Step 5, Method B

Q: Is this production-ready?
A: Yes! Just make sure to:
   - Use a strong password in appsettings.json
   - Protect the appsettings.json file with NTFS permissions
   - Configure HTTPS for external access
   - Setup regular database backups

================================================================================
TROUBLESHOOTING:
================================================================================

Problem: Can't login
Solution: Make sure you're using the EXACT password you put in appsettings.json
          Email is: admin@local

Problem: App won't start
Solution: Check that you have write permissions in the folder
          Try running as Administrator

Problem: Database errors
Solution: Make sure e_sqlite3.dll is in the same folder as ShiftManager.exe
          Delete app.db and restart to recreate

Problem: Port already in use
Solution: Another app is using port 5000
          Close other apps or change the port (see DEPLOYMENT_GUIDE.txt)

For more help, see DEPLOYMENT_GUIDE.txt and VERIFICATION_CHECKLIST.txt
