App works on localhost but shows Error 500 in IIS?

This is normal! It's just a configuration issue. Here's how to fix it:

═══════════════════════════════════════════════════════════════════════
SOLUTION 1: QUICK FIX (Try this FIRST - fixes 90% of issues)
═══════════════════════════════════════════════════════════════════════

On the IIS server:

1. Navigate to the FinalProductPublish folder
2. Right-click on: IIS_QUICK_FIX.bat
3. Select: "Run as administrator"
4. Wait for it to complete (30 seconds)
5. Open IIS Manager
6. Find your Application Pool → Right-click → Recycle
7. Refresh your browser (press F5)

✓ This should fix it!

If still error 500 → Continue to Solution 2

═══════════════════════════════════════════════════════════════════════
SOLUTION 2: SEE THE REAL ERROR
═══════════════════════════════════════════════════════════════════════

Generic "500" doesn't tell you what's wrong. Let's see the actual error:

1. Right-click on: IIS_ENABLE_DETAILED_ERRORS.bat
2. Select: "Run as administrator"
3. Press any key when prompted (it will restart IIS)
4. Refresh your browser
5. You'll now see a detailed error message instead of just "500"
6. Take a screenshot or write down the error
7. Open: IIS_500_ERROR_SOLUTIONS.txt
8. Search for your error message
9. Follow the solution

═══════════════════════════════════════════════════════════════════════
MOST COMMON CAUSES (and quick fixes)
═══════════════════════════════════════════════════════════════════════

90% of IIS 500 errors are one of these 3 issues:

┌────────────────────────────────────────────────────────────────────┐
│ #1: .NET Core Hosting Bundle Not Installed (40% of issues)        │
└────────────────────────────────────────────────────────────────────┘

SYMPTOMS:
- Error 500.0
- "ANCM In-Process Handler Load Failure"
- Just says "500 Internal Server Error"

FIX:
1. Download: .NET 8.0 Hosting Bundle from Microsoft
   https://dotnet.microsoft.com/download/dotnet/8.0
   (Look for "Hosting Bundle" for Windows Server)

2. Install it on your IIS server

3. Restart IIS:
   - Open Command Prompt as Administrator
   - Run: net stop was /y
   - Run: net start w3svc

4. Recycle your Application Pool in IIS Manager

5. Test again


┌────────────────────────────────────────────────────────────────────┐
│ #2: DLL Files Are Blocked (35% of issues)                         │
└────────────────────────────────────────────────────────────────────┘

SYMPTOMS:
- Error mentions "Could not load file or assembly"
- Error mentions "SixLabors.ImageSharp"
- Error mentions "FileLoadException"

FIX:
1. In FinalProductPublish folder:
   - Right-click: UNBLOCK_FILES.bat
   - Select: "Run as administrator"

2. Wait 30 seconds for it to complete

3. Open IIS Manager
   - Find your Application Pool
   - Right-click → Recycle

4. Test again


┌────────────────────────────────────────────────────────────────────┐
│ #3: Permission Issues (25% of issues)                             │
└────────────────────────────────────────────────────────────────────┘

SYMPTOMS:
- Error mentions "Access Denied"
- Error mentions "Permission Denied"
- Error mentions "unable to open database file"
- Can't create logs or database

FIX:
1. IIS_QUICK_FIX.bat already fixes this!
   (If you didn't run it yet, go back to Solution 1)

2. Or manually in Command Prompt as Administrator:
   cd C:\path\to\FinalProductPublish
   icacls . /grant "IIS_IUSRS:(OI)(CI)M" /T

3. Recycle Application Pool

4. Test again
